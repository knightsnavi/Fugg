FUGG CITY

An open-world city. Steal cars. Run jobs. Outrun the cops.

Keyboard + Mouse

  • WASD move / drive
  • Mouse look (click to lock)
  • Shift sprint   Space jump / handbrake
  • E enter / exit car   H horn
  • LMB fire / punch   RMB aim   Q / wheel weapon
  • C camera   Esc pause

Controller

  • L stick move / steer   R stick look
  • RT / LT gas / brake  (on foot: fire / aim)
  • A sprint / handbrake   X jump   LB/RB weapon
  • Y enter / exit car   B horn
  • Start pause   Back camera

Touch

  • Left thumb virtual stick
  • Right thumb drag to look
  • Buttons context actions
